⚙️ ROBUST PIPELINE

Ingestion Architecture & Sensor Integrity

Real AIS telemetry contains sensor noise, multi-receiver latency, and clock jitter. The ingestion engine enforces strict bounding, atomic output staging, and preserves raw observation provenance.

🛡️ Atomic Staging & Safe Overwrite

Ingestion writes exclusively to a randomized temporary database (.tmp.*.sqlite). It replaces destination databases only upon successful verification. If interrupted or failed, prior operational databases remain completely uncorrupted.

✓ Safe alphanumeric target naming validation
✓ Auto-stale lockfile detection with PID liveness check
✓ Memory-mapped SQLite with read-only proxy mode (?mode=ro)
📡 Same-Timestamp GPS Conflict Preservation

When two distinct shore stations record divergent positions for the same vessel at the exact same second, CableWatch retains both records with conflict markers instead of silently discarding observations.

✓ Missing fields distinguished from zero (sog=null vs 0.0 kn)
✓ Exact duplicates deduplicated for accurate dwell aggregation
✓ Conflict flags break sequential continuity assumptions

🧪 TRACK CONTINUITY

Experimental Multi-Fix Track Engine

Single-fix snapshots can misclassify brief maneuvers or normal turns. The experimental track score evaluates sustained historical behavior up to the replay second, enforcing strict sequential continuity.

🛡️ Strict Episode Continuity Breaking

A continuous dwell is broken whenever an intervening observation fails corridor qualification. For example, qualifying slow fixes at 00:00 and 00:20 with a fast transit at 00:05 breaks the run into two short intervals rather than a misleading 20-minute dwell.

✓ Breaks on speed > 3.0 kn or distance > corridor limit
✓ Breaks on reporting gap > 900 seconds (15 min)
✓ Unrounded seconds-based dwell threshold (≥ 900s)
⏱️ Truncation Safety & Chronological Integrity

The /track endpoint scans newest-first (ts ≤ at ORDER BY ts DESC), applies safety limits, and reverses order. When safety limits are reached, older fixes are truncated while the latest critical evidence is always preserved.

✓ Replay time bounded: zero look-ahead contamination
✓ Explicit UI warning banner if track hits safety limit
✓ Non-qualifying fixes transparently logged in evidence timeline

🔬 SHADOW MODE

ML Shadow Mode: Historical Pattern Comparison

Provides an independent, non-intrusive statistical second opinion beside single-fix and track scores. It ranks a vessel's trailing 60-minute behavior against historical reference distributions without altering queue priority.

1. Median SOG
Linear-interpolated median speed over 60m window.
2. SOG Spread (IQR)
Velocity dispersion (P75 - P25) to detect speed pulsing.
3. Slow Dwell Ratio
Bounded time fraction spent < 3.0 knots in the window.
4. Corridor Distance
Perpendicular distance to corridor centerline in km.
Strict Quality Gates (Fails Closed) Fail Safe
• ≥ 3 distinct timestamps
• ≥ 15 min observed span
• No gap > 15 min (900s)
• Newest fix age ≤ 15 min
• SOG missing rate ≤ 20%
• No GPS jumps > 50 kn
Engine 1: Robust Standardized Deviation

Computes median absolute deviation divided by interquartile range with documented noise floors: z = |x - median| / max(IQR, floor)

Engine 2: Empirical Anomaly Percentile

Ranks composite score against frozen reference scores with exact tie handling: Percentile = 100 * count(ref ≤ score) / N

⚠️
Operational Disclaimer: AIS behavioral telemetry does not prove physical anchor deployment, seabed contact, equipment damage, or hostile intent. Anomaly percentiles reflect statistical deviation from past traffic, not incident likelihood.
